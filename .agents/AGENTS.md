# Custom Rules for gonku-auth

The following rules must be strictly adhered to during all code generation and editing tasks for this project:

1. **No Unnecessary Comments**: Do not add unnecessary or redundant comments to the code. If there are existing outdated or useless comments, delete them.
2. **Best Practices & Common Implementations**: Always apply best practices and use the most common, modern implementations in the React/JavaScript ecosystem.
3. **Commit Guidelines**: Prefix commit messages with a keyword indicating the type of changes made (e.g. `(feat): implement user search`, `(fix): adjust table styles`).
